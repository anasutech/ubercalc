# حاسبة ربح الرحلة — تطبيق أندرويد

تطبيق يقرأ محتوى شاشة طلب الرحلة بتطبيق **Uber Driver** تلقائيًا (عن طريق Accessibility
Service)، يحسب الربح الصافي والدخل بالساعة فورًا، ويعرضهم بفقاعة عائمة صغيرة فوق الشاشة.
**أنت اللي تقرر تقبل أو ترفض يدويًا داخل تطبيق أوبر** — التطبيق لا يضغط أي زر ولا
يتفاعل مع أوبر، فقط يقرأ ويعرض رقم.

---

## 0. أسهل طريقة — بناء APK جاهز بدون Android Studio (عن طريق GitHub)

المشروع فيه ملف جاهز (`.github/workflows/build.yml`) يخلي GitHub يبني لك ملف APK
تلقائيًا بالسحابة. الخطوات:

1. سوّي حساب مجاني على [github.com](https://github.com) إذا ما عندك.
2. اعمل Repository جديد (فاضي)، خليه **Public** أسهل، وارفع له محتويات هذا المجلد
   كامل (تقدر تسحب وتفلت الملفات من موقع GitHub مباشرة بدون أي أوامر — زر
   "Add file" ← "Upload files").
3. بعد الرفع، روح تبويب **Actions** بأعلى صفحة الـ Repository.
4. أول رفع للكود بيشغّل البناء تلقائيًا (أو اضغط "Run workflow" لو ما اشتغل لحاله).
5. انتظر 3-5 دقايق لين تخلص، بعدين انزل لقسم **Artifacts** بنفس الصفحة وحمّل
   `RideProfitCalc-debug-apk` — ملف مضغوط جواه الـ APK.
6. انقل ملف الـ APK لجوالك (عبر رابط تحميل مباشر أو USB)، افتحه، ووافق على
   "تثبيت من مصادر غير معروفة" لما يطلب منك أول مرة، وثبّته عادي.

بكذا ما تحتاج تفتح Android Studio ولا تعدّل أي سطر كود — بس ترفع الملفات وتحمّل
الناتج. **الاستثناء الوحيد** هو خطوة تعديل أنماط قراءة الشاشة (بالقسم 3 تحت) لو
لقيت الأرقام ما تتلقط صح — تلك خطوة تعديل نص بسيطة تقدر تسويها من موقع GitHub
نفسه (زر التعديل ✏️ بأعلى الملف) بدون تثبيت أي برنامج.

---

## 1. الطريقة البديلة: فتح المشروع بـ Android Studio

1. حمّل [Android Studio](https://developer.android.com/studio) (مجاني).
2. افتح Android Studio ← `Open` ← اختر مجلد `RideProfitCalc`.
3. خلي Android Studio يعمل Sync تلقائي (بيحمّل Gradle وGoogle repos، يحتاج إنترنت أول مرة فقط).
4. وصّل جوالك (فعّل USB Debugging) أو استخدم محاكي، واضغط ▶ Run.

## 2. أول تشغيل على الجوال

1. افتح التطبيق ← اضغط **"فتح إعدادات إمكانية الوصول"** ← فعّل "حاسبة ربح الرحلة".
2. ارجع للتطبيق ← اضغط **"فتح إعدادات العرض فوق التطبيقات"** ← فعّل الصلاحية.
3. عدّل الأرقام (سعر بنزين، استهلاك سيارتك، هدفك بالساعة) واضغط **حفظ الإعدادات**.
4. افتح تطبيق أوبر وابدأ تستقبل طلبات — الفقاعة تظهر تلقائي فوق شاشة الطلب.

## 3. ⚠️ الجزء الأهم: لازم تعدّل أنماط القراءة (Regex) بنفسك

أوبر يغيّر تصميم شاشة طلب الرحلة بشكل دوري، وتختلف الأرقام المعروضة حسب الدولة
واللغة. أنا كتبت الكود بأنماط شائعة لأمريكا بالإنجليزي:

- الأجرة: `$18.42`
- المسافة: `12.3 mi`
- الوقت: `24 min`

هذي الأنماط موجودة بملف:
```
app/src/main/java/com/rideprofit/calc/RideCalculator.kt
```
داخل كائن `FareParser` (المتغيرات `fareRegex` و`milesRegex` و`minutesRegex`).

**كيف تتأكد أنها شغالة صح:**

1. حمّل تطبيق **Accessibility Scanner** من Google Play (مجاني من Google نفسها).
2. افتح تطبيق أوبر على شاشة طلب رحلة حقيقية (أو خذ سكرين شوت).
3. شغّل Accessibility Scanner وشوف بالضبط كيف مكتوبة الأرقام (فيه $ قبلها؟ فيه مسافة؟
   الكلمة "mi" و"min" أو "miles" و"minutes"؟).
4. إذا مختلفة عن الأنماط الموجودة، عدّل الـ Regex بملف `RideCalculator.kt` وأعد التشغيل.

بدون هذي الخطوة، احتمال كبير التطبيق ما يلقط الأرقام صح من أول مرة.

## 4. تحذيرات مهمة

- **ما يقبل ولا يرفض شي بالنيابة عنك** — بس يعرض رقم، القرار كله يدك.
- قراءة شاشة تطبيق ثاني تلقائيًا نوع من الأتمتة، وبعض شروط استخدام أوبر قد تتحفظ
  على هذا النوع من الأدوات. أنا مو محامي وهذا مو نصيحة قانونية — القرار يرجعلك.
- التطبيق ما يرسل أي بيانات لأي سيرفر خارجي؛ كل القراءة والحساب محلي بجهازك فقط.
- لو أوبر حدّث تصميم التطبيق وتغيرت الأنماط، الفقاعة ممكن توقف تشتغل لين تعدّل الـ Regex.

## 5. بنية الملفات

```
RideCalculator.kt      → منطق الحساب + استخراج الأرقام من النص (Regex)
Prefs.kt                → حفظ/تحميل إعداداتك (بنزين، استهلاك، هدف)
RideAccessibilityService.kt → يقرأ شاشة أوبر ويستدعي الحساب
OverlayService.kt       → يعرض الفقاعة العائمة فوق الشاشة
MainActivity.kt         → شاشة الإعدادات وطلب الصلاحيات
```
